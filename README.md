## 📱 核心亮点与原型还原

1. **手绘原型 100% 还原**：
   - **上半区**：左侧为「我的清单」（垂直滚动，快捷新增/编辑/删除），右侧为「其他人清单」（横向滑动切换多位好友，纵向滚动查看物品）。
   - **清新配色**：每位用户的清单拥有专属的马卡龙清新底色（薄荷绿、暖杏黄、海盐蓝、香芋紫等），视觉分明不刺眼。
   - **下半区**：全宽网格平铺「最终清单」，智能汇总所有物品。
2. **撞车特别标识（重复）**：
   - 当多个用户添加了相同物资（如小明带了羊肉串、大山也带了羊肉串），该物资在最终清单中会以**醒目暖色边框 +【重复】标签**呈现，并标出总份数。点击卡片可查看每位携带者的明细。
3. **底部四栏功能闭环**：
   - **首页**：协同备料工作台（手绘原型主视图）。
   - **推荐库**：针对露营场景精选数十种高频装备与食材（栖居装备、美食炊具、照明动力、防护清洁），支持一键选它或批量导入「我的清单」，解决漏带痛点。
   - **清单核对**：露营出发或装车时的打钩清点 Checklist，支持进度条实时统计。
   - **我的**：个人信息、活动创建/加入（通过 6 位邀请码）、以及**一秒切换测试账号**（小明、大山、阿杰、露露），无需退出即可模拟多人协同！
4. **技术架构**：
   - 纯原生零编译依赖：Node.js v24 原生 SQLite (`DatabaseSync`) + Express。
   - 移动端优先响应式 UI：完美兼容各种手机屏幕长宽比、全面屏安全区（Safe-Area）适配。

## 🚀 启动与体验方式

服务默认已在后台运行在 `3000` 端口：

### 1. 电脑端浏览器访问
直接在浏览器打开：
👉 [http://localhost:3000](http://localhost:3000)

*(在电脑浏览器中会自动呈现逼真的手机外观模拟器，支持所有触摸滑动交互)*

### 2. 手机端真机体验（推荐！）
只要手机与电脑连入同一个 WiFi 网络，手机浏览器打开：
👉 **`http://192.168.1.199:3000`**

## 🐳 飞牛 OS (fnOS) / Docker 部署与代码热更新

项目已全面适配 **飞牛 OS (fnOS)** NAS 容器环境，提供官方 `docker-compose.yml` 与 `Dockerfile`：

* 🚀 **支持代码与前端实时热挂载**：直接在 NAS 共享文件夹内修改/覆盖 `public/`（前端）和 `server/`（后端）代码，无需重启容器，前端刷新即看、后端自动热重启！
* 💾 **数据持久化保护**：数据库持久保存在宿主机 `data/` 目录，容器销毁重建数据不丢失。
* 📖 详细图文操作请见：[飞牛 OS (fnOS) Docker 部署与热更新指南](./docs/FNOS_DEPLOY.md)。
