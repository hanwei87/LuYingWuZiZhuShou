# 「大家一起选」交互设计与视觉系统规范

本文档详述「大家一起选」在移动端人机交互（HCI）、触控手势、大拇指热区、视觉反馈及清新配色系统的具体规范。

---

## 1. 交互设计核心原则

1. **单手大拇指热区优先 (Thumb Zone Priority)**：
   * 手机端单手握持时，屏幕中下部为最佳触控区。
   * 因此核心操作（快捷添加、卡片编辑、清点打钩、底部四栏切换）均布局在视口中下部或采用由底部滑出的 Action Sheet 抽屉。
2. **防误触与安全确认 (Error Prevention)**：
   * 移动端屏幕空间紧凑，不采用直接露出的小垃圾桶图标（极易发生误删）。
   * 采用“轻触卡片唤起抽屉 $\rightarrow$ 底部醒目红键删除 $\rightarrow$ 系统级二次确认”的安全路径。
3. **状态即时透明 (Immediate Feedback)**：
   * 任何添加、修改、删除或打钩操作，均在 0.2 秒内给予视觉变化，并伴随顶部 Toast 轻气泡提示。
4. **横纵手势隔离 (Gesture Separation)**：
   * 左侧为纯纵向滚动，右侧外层为横向滚动、内层为纵向滚动，通过 CSS `touch-action` 与 `scroll-snap` 实现手势明确解耦，无滑动冲突。

---

## 2. 关键交互流程与动效规范

### 2.1 快捷添加物资交互
* **触发方式**：
  * 左下角常驻输入框，点击唤起手机软键盘。
  * 用户输入物品名称后，点击软键盘右下角「完成/换行/前往」按键或点击绿色的「＋」按钮。
* **动效与反馈**：
  * 输入框文字立即清空并保留光标聚焦，方便连续添加下一项。
  * 新物资插入到「我的清单」顶部或底部，伴随 `fade-in` 动效。
  * 下半区「最终清单」实时完成品名聚合计算，屏幕顶部弹出 Toast：「已添加『羊肉串』」。
* **个人清单同名拦截反馈**：
  * 若尝试添加或重命名为自己清单中已有的物资，输入框自动高亮选中并触发 Toast 拦截提示：「您的清单中已存在【xxx】，不可重复添加」，引导用户直接调整数量步进器，杜绝重复卡片产生。

### 2.2 编辑与删除抽屉 (Action Sheet)
* **唤起方式**：在左侧「我的清单」轻点任意卡片。
* **呈现形态**：自视口底部向上平滑滑出（`animation: slideUp 0.25s cubic-bezier(0.16, 1, 0.3, 1)`），背景施加 4px 毛玻璃遮罩。
* **操作控件**：
  * **品名输入框**：支持修改拼写。
  * **数量调节器 (Stepper)**：提供大号「-」和「+」按键（尺寸 $\ge 40\times 40\text{px}$），单手点按无压力。
  * **删除按键**：浅红背景弱化焦虑，点击时触发安全确认弹窗，确认后抽屉收回并移除条目。

### 2.3 好友横滑清单手势交互
* **手势**：大拇指在右侧区域向左横扫（Swipe Left）。
* **吸附动效**：启用 CSS `scroll-snap-type: x mandatory;`，手指离开屏幕时卡片自动吸附对齐至最近的好友列起始边缘，滑动手感平滑紧凑。
* **边界引导**：首屏右侧边缘预留下一位好友卡片的 20%~30% 露白，提供无声的手势暗示。

### 2.4 最终清单“重复”撞车视觉与明细穿透
* **普通物品**：白底淡灰边框，低调规整。
* **重复物品（撞车状态）**：
  * **外框动效**：淡暖红底色 (`#FFF5F5`) + 珊瑚红边框 (`#FF8787`)。
  * **角标徽章**：右上角醒目渐变红底【重复】药丸标，字号 9px 粗体。
  * **总份数标签**：如 `总数: ×5`。
* **点击穿透**：
  * 点击该卡片唤起「撞车成员明细抽屉」。
  * 抽屉中罗列所有准备该物资的朋友（如：*小明 2把、大山 3把*），各自带有其专属颜色标签，清晰透明。

### 2.5 推荐库一键挑品与批量导入
* **单选模式**：点击卡片右侧「+ 选它」，按钮立刻变为置灰状态「✓ 已添加」，物资秒速进库。
* **多选批量模式**：勾选多张卡片左侧圆圈，右上角常驻「已选 N 项」及激活状态的「加入我的清单」大按钮，一次性打包加入。

### 2.6 清单核对打钩微动效
* **触控目标**：整行卡片或大号圆圈均可响应轻触。
* **打钩动效**：未勾选状态为空心灰圈，点击后瞬间变为绿色实心勾选圈，物资标题添加中划线并降低透明度，平滑过渡至下方的「已就绪」分组中。

### 2.7 实时协同无感更新与跳出动效 (SSE Realtime Experience)
* **无感更新**：远端好友在另一台手机操作时，当前屏幕通过标准 SSE 长连接静默接收事件并在后台重绘，无需手动下拉刷新，不中断用户正在进行的滚动或编辑流程。
* **条目跳出弹性动效 (Pop Bounce)**：新加入的条目附带 `itemPopBounce` 关键帧弹性放大动效（缩放 $0.82 \rightarrow 1.06 \rightarrow 1.0$），伴随翠绿外发光，带来直观生动的“好友刚刚放入物资”的协同质感。
* **灵动浮层横幅 (Dynamic Island Notice)**：自顶部导航下方平滑滑出半透毛玻璃深色胶囊横幅（如：`⚡ 大山 刚刚添加了【便携气罐 ×2】`），伴随移动端震动反馈（`navigator.vibrate(40)`），停留 3.2 秒后优雅收起。
* **核对进度胶囊 (Ratio Pill)**：清单核对成员标签中的准备情况采用精美微胶囊（如 `0/8`、`✓ 4/4`），去除冗余括号，运用等宽字体（Tabular Nums）与多级色彩层级，彻底告别单调文本。

## 4. 触觉反馈与动效参数表

| 动效场景 | CSS 属性 | 参数设定 | 视觉感受 |
| :--- | :--- | :--- | :--- |
| **所有按钮点按态** | `transform` | `scale(0.97)`，耗时 `150ms` | 像物理按键被轻轻按下的弹性触感 |
| **底部抽屉滑出** | `transform` | `translateY(100%) -> translateY(0)` | iOS 风格平滑底部弹出，阻尼自然 |
| **Toast 气泡升起** | `opacity, transform` | `translate(-50%, -10px) -> (0, 0)` | 悬浮提示，不干扰主操作区 |
| **核对打钩划线** | `text-decoration` | `line-through` + `opacity: 0.6` | 直观完成感，心理满足度高 |
